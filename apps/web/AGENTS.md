# Cassy guest PWA (`apps/web`)

Read the root `AGENTS.md` first.

## Stack
Next.js 15 App Router, React 19, TypeScript, Tailwind CSS v4, Playwright with axe. Server Components by default; client components only for interactive parts (cart, options sheet, payment).

## Rules
- Colour comes only from `src/app/tokens.css`, generated by `packages/design-tokens/build-tokens.mjs`. Never edit it by hand. The outlet colour is applied by `brandVariables()` in `src/lib/brand.ts`, which falls back to ink when the colour is missing or fails 4.5:1.
- Icons: `lucide-react`, imported per icon. Decorative icons get `aria-hidden`; icon-only buttons get an `aria-label`.
- Copy lives in `src/lib/messages.ts` (ID and EN). No inline UI strings.
- Mobile first, 320 px reflow without horizontal scroll, touch targets 44 px or more, primary actions in thumb reach at the bottom.
- Never calculate price or tax in the browser; render the server quote.
- Live order status uses the WebSocket hook with backoff and falls back to polling.

## Commands
```bash
pnpm dev          # http://localhost:3000
pnpm typecheck
pnpm test:unit
pnpm test:e2e     # Playwright + axe; must stay green
```
