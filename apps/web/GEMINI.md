# MyCaffe Guest Ordering & Backoffice PWA: GEMINI.md

## Ecosystem Context & Role
This sub-workspace is the **Guest Table Ordering & Owner Backoffice PWA** (`apps/web` inside `C:\Projects\MyCaffeClient`).
Built with **Next.js 15 App Router**, React 19, TypeScript, and Tailwind CSS v4.

### Guidelines
- Mobile-first responsive layout ($360\text{px} - 430\text{px}$ viewports).
- Real-time order tracker with failover to HTTP polling.
- Zero emojis in code, meta tags, or UI copy.
- Enforce WCAG 2.2 AA accessibility standards.
